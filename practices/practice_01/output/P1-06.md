+
+  Scenario: Позитивный ответ при валидном diff
+    Given валидный JSON с полем diff типа string и длиной ≤ 20000 символов
+    When отправляем POST /api/reviews с этим JSON
+    Then получаем 200 OK и тело содержит поля summary (string),
+         risks (array, размер ≤ 3, каждый объект имеет file (string), line (number), evidence (string), risk (string)),
+         checks (array of strings)
+    And логи содержат request_id, длительность и статус; содержимое diff и ответа не логируется
+
+  Scenario: Ошибка при отсутствии поля diff
+    Given JSON без поля diff
+    When отправляем POST /api/reviews
+    Then получаем контролируемую 4xx-ошибку (точный формат ошибки обсуждается)
+
+  Scenario: Ошибка при слишком длинном diff
+    Given JSON с полем diff длиной > 20000 символов
+    When отправляем POST /api/reviews
+    Then получаем 413 Payload Too Large
+
+  Scenario: Таймаут внешнего LLM
+    Given валидный JSON с полем diff
+    And внешний вызов LLM превышает 10 секунд
+    When отправляем POST /api/reviews
+    Then получаем контролируемый ответ об ошибке, не ждём > 10 секунд
