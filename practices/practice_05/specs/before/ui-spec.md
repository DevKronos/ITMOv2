# UI: массовое прочтение — исходная версия
В разделе уведомлений добавить форму «Прочитать уведомления текущего города».
Показывать название города рядом с действием. Кнопка активна при сохранённом
городе и unread>0; иначе disabled. История всех городов остаётся видимой.
После POST и перехода на главную показать сообщение с количеством прочитанных.
Без непрочитанных отображать 0; при ошибке показать русское сообщение.
Сценарий приёмки: город Санкт-Петербург, 2 новых уведомления; нажатие даёт 0
на счётчике и сообщение о двух изменениях. Карточки других городов сохраняются.
Индивидуальные кнопки и поиск остаются доступны.
