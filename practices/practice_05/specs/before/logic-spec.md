# Логика: массовое прочтение — исходная версия
Операция массового прочтения получает текущий сохранённый город из preferences.
Нормализует город существующей normalize_city, обновляет notifications.is_read
с 0 на 1 только при совпадении city_key. Возвращает число реально изменённых строк.
Пустой город даёт ValueError без изменений. Обновление атомарно, история не удаляется.
Повтор даёт 0; нет уведомлений — 0. Город, подписки и promotions не меняются.
HTTP POST использует существующий same-origin middleware, результат — redirect.
Сценарии приёмки: два города изолированы, прочитанные не входят в число изменений,
нормализованные алиасы работают, пустой профиль не меняет историю.
