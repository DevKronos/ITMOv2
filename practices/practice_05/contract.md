# Контракт UI и логики: прочтение текущего города
## Операции и данные
`GET /` показывает все notifications и unread только для normalize_city(city).
Форма `POST /notifications/read-city`, Content-Type application/x-www-form-urlencoded,
передаёт обязательный `expected_city: str` (исходный city на показанной странице).
Кнопка «Прочитать уведомления текущего города» disabled при отсутствии города или unread=0.

`storage.mark_city_read(expected_city: str) -> int`:
1. Проверить непустую строку после strip и длину <=100; иначе ValueError.
2. В одной SQLite BEGIN IMMEDIATE транзакции прочитать preferences.city.
3. Нормализовать оба города existing normalize_city; пустой ключ или несовпадение — ValueError.
4. UPDATE только `city_key = current_key AND is_read = 0`, установить is_read=1.
5. Вернуть rowcount >=0 и commit. Ошибка — rollback, никаких частичных изменений.

Город формы — предусловие, SQL использует сохранённый город. Нормализованные алиасы
(«СПб»/«Санкт-Петербург») допустимы. Новое уведомление после commit остаётся новым.
Город, подписки, данные/количество/порядок истории и каталог не меняются.

## Результаты и ошибки
| Состояние | HTTP | Результат |
|---|---|---|
| N непрочитанных текущего города | 303 → /?message=… | «Отмечено прочитанными: N» |
| Повтор / нет записей | 303 | «Отмечено прочитанными: 0» |
| Пробельный/длинный expected_city или пустой профиль | 303 | «Сохраните город перед отметкой уведомлений»; без записи |
| Нормализованный город формы устарел | 303 | «Город изменился. Обновите страницу и повторите действие»; без записи |
| Поле отсутствует или равно пустой строке | 422 | стандартная FastAPI ошибка; без записи |
| Чужой Origin | 403 | существующее «Запрос с другого сайта отклонён»; без записи |
| GET вместо POST | 405 | без записи |

HTML экранирует город и сообщения. После redirect read-карточки и unread получаются
из storage.read_state. Все города остаются в истории. Действие работает без JavaScript.
Индивидуальный POST /notifications/{id}/read сохраняется. POST сбрасывает q,
как другие существующие команды; поиск не влияет на область массовой отметки.

Уточнение 1.1 после проверки: FastAPI обязательный Form считает пустую строку
отсутствующим полем (422). Строка из пробелов доходит до storage (ValueError →303).
Прямая storage.mark_city_read('') по-прежнему даёт ValueError.
