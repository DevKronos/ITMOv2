# Design
GET / читает q из query_params; чистая функция search_promotions(promotions,q)
возвращает список и бросает ValueError на длину >100 после нормализации.
Нормализация отдельная от городских алиасов. Ошибка перехватывается main.index,
полный список остаётся видимым. Jinja экранирует q; поиск до добавления UI labels.
Счётчик показывает длину найденного списка. /api/state остаётся полным.
Нет миграций, внешней сети, frontend сборки или JS для поиска.
