# Принципы «Акции рядом»
Версия 1.0.0; принята 25.10.2026.
1. Сохранять город, подписки, историю и пользовательские данные; никаких сбросов БД.
2. HTTP и Jinja отвечают за интерфейс; SQL в storage, чистые правила в domain.
3. Никаких новых runtime-зависимостей, внешней доставки и миграций без необходимости.
4. До кода фиксировать проверяемые требования и контракт; изменения требований предшествуют коду.
5. Проверять весь HTTP→логика→БД→HTML путь и регрессии на временной базе без сети.
