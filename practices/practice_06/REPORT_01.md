# Отчёт 1. Атаки на исходный сервис

Проверен собственный HTTP-процесс на loopback, все данные синтетические. Снимок исходного сервиса: `evidence/before/service.py.txt`. Воспроизведение: из текущей папки `python3 lab/security_probe.py evidence/before` на исходной версии. Сценарий удаляет только временные файлы Sandbox и закрывает сервер. После исправлений эта команда проверяет уже исправленный код; снимок позволяет повторить исходный эксперимент в отдельной копии.

Полные запросы, тела, статусы и ответы: `evidence/before/http-evidence.json`. Токены в нём относятся к уже закрытому учебному процессу. Исходные функциональные тесты: 16 тестов OK (`baseline-tests.txt`). Новые проверки на исходной версии: 35 тестов, 20 failures и 1 error (`security-tests.txt`); часть контрактных тестов наследуется и остаётся успешной.

| Проблема | Доказательство (имя запроса в HTTP evidence) | Эффект / риск |
|---|---|---|
| Отсутствие аутентификации и IDOR | anonymous_profile, foreign_profile, foreign_orders, foreign_context | Анонимный доступ и чтение профиля/заказов bob клиентом alice; высокий |
| SQL-инъекции в profile, search, assistant/context | sql_profile, sql_search, sql_context | `1 OR 1=1` и `' OR 1=1 --` раскрывают строки обоих клиентов; высокий |
| Подмена роли | forged_role | X-Role: staff позволяет alice выгрузить все профили; высокий |
| Цена из клиентского тела | price_override | Заказ lamp создаётся за -1 вместо 1500; высокий |
| Чужой файл и traversal внутри Sandbox | foreign_file, traversal | Чек bob и TEST_ONLY_OPERATOR_SECRET; высокий |
| Сохранённый XSS | review_xss, render_xss | HTML возвращает необработанный script; высокий. Выполнение в браузере отдельно не проверялось |
| Утечка секретов через журнал | logs | Доступны пароль входа, X-Token и тела запросов; высокий |
| Неавторизованные инструменты | tool_read, tool_export, tool_delete | Чтение заметки, экспорт профилей, удаление корня учебных файлов; высокий |
| Неверная обработка JSON и исключений | malformed_body, files_after_delete | 500 с типом исключения и деталями; средний |
| Недоверенные отзывы в AI-контексте | injection_review, injected_context | Инструкция из отзыва попадает в prompt; возможна непрямая prompt injection, результат реальной модели учитывается отдельно |

По коду дополнительно установлены: неограниченный рост журналов, отзывов и сессий, отсутствие истечения сессии и ограничения попыток входа, слабая проверка типов. Это наблюдения исходников; нагрузочная атака не проводилась.

Прямая передача опасных решений исполнителю подтверждает отсутствие проверки полномочий, но не подчинение LLM инъекции. Точный контекст сохранён в context-clean.json и context-injected.json. Физическая граница Sandbox не обходилась и не изменялась.

Сохранённые ответы модели на исходных контекстах: `evidence/before/model-clean.json` и `evidence/before/model-injected.json` — оба `refuse`. Таким образом, попадание инструкции в prompt подтверждено, но успешное подчинение модели этой инструкции не наблюдается. По сообщению пользователя, при ручном исполнении обоих ответов исходный исполнитель вернул `unknown tool`; HTTP-статусы неизвестны, оригинальные HTTP-логи этих запусков не сохранены; сравнение до/после и ограничения доказательств приведены в `REPORT_02.md` и `evidence/MODEL_STATUS.md`.
